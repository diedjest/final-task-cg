# **Проект: 3D Model Viewer Pro**

Этот проект представляет собой просмотрщик 3D-моделей, написанный на Java. Он предназначен для загрузки, рендеринга и манипуляции 3D-моделями. В проекте реализованы сложные математические алгоритмы, включая аффинные преобразования, линейную алгебру и алгоритмы 3D-рендеринга, созданные с нуля без использования внешних 3D-библиотек.

## **Обзор**

Основа приложения - обработка и визуализация 3D-данных. Программа парсит файлы формата .obj, вычисляет нормали и отрисовывает полигональную сетку на 2D-холсте (Canvas). Проект демонстрирует глубокое понимание принципов компьютерной графики, включая графический конвейер, матрицы трансформаций (Model, View, Projection) и такие методы рендеринга, как плоское и плавное (Gouraud) затенение, Z-буферизация и базовое текстурирование.

## **Ключевые особенности**

> * **Парсинг .obj файлов:** Надежный кастомный парсер для извлечения вершин, текстурных координат, нормалей и данных полигонов.  
> * **Математический движок:** Комплексный набор математических классов, разработанный с нуля. Включает операции с Vector2, Vector3, Vector4, Matrix3 и Matrix4, необходимые для 3D-графики.  
> * **Аффинные преобразования:** Реализация переноса, вращения (с использованием как углов Эйлера, так и кватернионов для избежания шарнирного замка) и масштабирования. Паттерн Builder используется для эффективного конструирования сложных матриц трансформации.  
> * **Система камеры:** Виртуальная камера с перспективной проекцией, поддерживающая панорамирование, масштабирование и вращение вокруг цели.  
> * **Движок рендеринга:** Программный рендер, использующий JavaFX Canvas для отрисовки. Включает:  
  * Режимы каркасного (Wireframe) и сплошного (Solid) рендеринга.  
  * Отсечение нелицевых граней (Back-face culling) для оптимизации производительности.  
  * Алгоритм Z-буфера для правильной сортировки перекрывающихся полигонов по глубине.  
  * Модели освещения: Плоское затенение и плавное затенение с фоновой (ambient), рассеянной (diffuse) и зеркальной (specular) компонентами.  
  * Базовое наложение текстур.  
  * Алгоритм триангуляции полигонов (Fan Triangulator) для разбиения сложных многоугольников на треугольники.  
> * **Интерактивный UI:** Современный интерфейс на JavaFX, позволяющий пользователям манипулировать моделями, настраивать параметры рендеринга в реальном времени и переключаться между светлой и темной темами.  
> * **Редактирование моделей:** Возможность выделения и удаления отдельных вершин или полигонов прямо из загруженной модели.

## **Моя роль и достижения**

В качестве тимлида команды из трех человек я отвечал за координацию общей архитектуры проекта, уделяя особое внимание бэкенд-логике и ядру математического движка.

### **Реализация математического ядра**

Я разработал базовую математическую библиотеку, необходимую для всех 3D-операций. Это включало создание кастомных классов для векторов и матриц с упором на точность и производительность.

> * **Матричные операции:** Реализованы алгоритмы матричного умножения, транспонирования и нахождения обратной матрицы (с использованием алгебраических дополнений для матриц 4x4).  
> * **Векторная математика:** Вычисление скалярного и векторного произведений, нормализация и работа с однородными координатами (Vector4), что критически важно для перспективной проекции.

### **Система аффинных преобразований**

Я спроектировал систему AffineBuilder - надежный механизм для применения трансформаций.

> * Реализованы как стандартные матричные вращения, так и вращения на основе кватернионов (RotateTransformationOnQuad) для обеспечения стабильного и непрерывного вращения.  
> * Использованы паттерны проектирования Builder и Composite, что позволяет связывать трансформации в цепочки и эффективно вычислять итоговую матрицу.

### **Тестирование и надежность**

Для обеспечения стабильности ядра я написал обширный набор модульных тестов с использованием JUnit. Этот набор тестов покрывает граничные математические случаи, проверяя точность векторных операций, обращений матриц и комбинаций трансформаций. Наличие этих тестов гарантирует надежность всего конвейера рендеринга.

## **Запуск проекта**

### **Требования**

> * Java Development Kit (JDK) 17 или выше.  
> * Установленный и настроенный Maven.

### **Сборка и запуск**

Вы можете запустить приложение напрямую, используя Maven Wrapper, включенный в проект:  
`# Компиляция проекта`  
`./mvnw clean compile`

`# Запуск приложения`  
`./mvnw javafx:run`

Альтернативный вариант - собрать готовый исполняемый JAR-файл:  
`./mvnw clean package`  
`java -jar target/final-task-cg.jar`

### **Использование**

> 1. Используйте **Файл \-\> Открыть модель** для загрузки .obj файла.  
> 2. Используйте элементы управления на левой панели для настройки параметров рендеринга (каркас, освещение, Z-буфер).  
> 3. Управление камерой с помощью мыши:  
   * **Левая кнопка \+ Перетаскивание:** Перемещение камеры (Pan).  
   * **Средняя кнопка \+ Перетаскивание:** Вращение камеры вокруг модели.  
   * **Прокрутка колесика:** Приближение и отдаление (Zoom).  
> 4. Используйте правую панель для просмотра статистики модели и изменения базового цвета.
